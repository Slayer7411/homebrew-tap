# homebrew-tap

```
brew install --cask slayer7411/tap/minos-741
```

update: `brew upgrade --cask --greedy minos-741`

* [MINOS-741](https://github.com/Slayer7411/MINOS-741) -> dj app for macos, always the latest release dmg
* the app is not signed by apple, the cask removes the quarantine flag after install
